# Coffey Vidzro

Personal website for Coffey Vidzro, a Ghanaian software engineer and founder of Leamout.

Website: https://vidzro.com

## Development

This site uses Astro, TypeScript, MDX, Bun, and Cloudflare Workers.

```sh
bun install
bun run dev
```

To validate the project:

```sh
bun run check
bun run build
```

## Pages

- `/`: Introduction
- `/about`: Background
- `/now`: Current focus
- `/uses`: Tools and technologies

Articles are authored in `src/content/writing`.
